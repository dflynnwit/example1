# Agile Software Development - Portfolio Example

## Overview
This repository demonstrates practical knowledge of Agile Software Development methodologies gained during my undergraduate/postgraduate studies. It showcases key Agile practices, artifacts, and real-world applications of Scrum and Kanban frameworks.

## Contents

### 1. Agile Methodologies Documentation
- **Scrum Framework**: Sprint planning, daily standups, retrospectives
- **Kanban**: Flow-based work management
- **XP Practices**: Pair programming, TDD, continuous integration

### 2. Project Artifacts
- User stories and acceptance criteria
- Sprint planning documents
- Sprint retrospectives
- Definition of Done (DoD)
- Product backlog management

### 3. Sample Projects
- **Task Management System**: A demonstration project following Agile principles
- Test-Driven Development (TDD) examples
- Continuous Integration/Deployment setup

### 4. Documentation
- Team collaboration guidelines
- Agile ceremonies templates
- Metrics and burndown charts
